## 每次实验必须记录

- Git commit 与配置文件路径
- 模型、预训练权重、输入尺寸、seed
- epoch、batch、optimizer、学习率、数据增强
- Precision、Recall、mAP50、mAP50-95、AP_small、分类别 AP
- Params、FLOPs、checkpoint/ONNX/engine 大小
- GPU、驱动、CUDA、cuDNN、TensorRT 版本
- TensorRT precision、batch、shape、warmup、迭代次数
- GPU compute、host latency、端到端 latency、FPS、峰值显存

## 公平性规则

- 主消融一次只改变目标变量。
- 不把不同输入尺寸、硬件、batch 或推理框架的 FPS 放在同一公平比较列。
- INT8 校准数据仅从训练集选择，验证集不参与校准。
- 论文未报告的数据写“未报告”，不得估算成论文结果。
- 最终模型与 Baseline 使用三个固定随机种子，报告均值和标准差。
