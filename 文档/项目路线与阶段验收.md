# 项目路线与阶段验收

## 总原则

模型改进严格按照以下因果链展开：

1. 小目标下采样后细节丢失：研究受控计算量的 P2 检测分支。
2. 浅层细节与深层语义融合不足：研究轻量可学习加权融合。
3. P2 带来高分辨率计算开销：压缩高分辨率 Neck，并以蒸馏恢复精度。
4. 理论轻量化不代表 GPU 更快：用 TensorRT 实测决定模块去留。

## 阶段 0：调研和环境冻结

任务：

- 精读 `文档/文献调研.md` 中的优先文献。
- 记录 Python、PyTorch、Ultralytics、CUDA、cuDNN、TensorRT、驱动版本。
- 确定训练配置、随机种子和实验目录规范。
- 获取 VisDrone2019-DET，编写可重复的数据转换与检查脚本。

验收：数据统计可复现，环境版本有记录，不存在无效或越界标签。

## 阶段 1：可信 Baseline

- 训练 YOLOv8n 640。
- 复现同配置至少两次，最终关键结果使用三个随机种子。
- 输出 mAP50、mAP50-95、AP_small、分类别 AP、Params 和 FLOPs。
- 导出 ONNX，并构建 TensorRT FP16 engine 做第一次延迟测试。

验收：训练、验证、导出、C++ 或 trtexec 推理链路全部跑通后才修改网络。

## 阶段 2：P2 分支

实验顺序：普通 P2 -> 限制通道的轻量 P2 -> 不同 P2 通道宽度。

验收：相对于 Baseline，AP_small 的改善必须结合 FLOPs 和 TensorRT 延迟评价。若代价不可接受，缩减或放弃 P2，而不是默认保留。

## 阶段 3：加权多尺度融合

比较 Concat、Add、等权融合和非负归一化可学习权重。优先只改 P2/P3 高分辨率路径，再判断是否扩展到完整 Neck。

验收：控制输出通道一致，证明收益不是通道数变化造成；确保 ONNX 无自定义算子。

## 阶段 4：轻量化与蒸馏

- 仅压缩 P2/P3 Neck 和检测头的高成本部分。
- 候选算子先通过 TensorRT 微型实测；不以 FLOPs 单独决策。
- YOLOv8s 作为教师，先做输出/定位蒸馏，必要时增加有限的特征蒸馏。

验收：轻量结构相对未轻量改进模型降低实际延迟；蒸馏不增加推理开销。

## 阶段 5：最终实验

- 完整消融 A0-A5。
- YOLOv8n、YOLOv8s、YOLO11n 和最终模型公平对比。
- 640/960 分辨率对照。
- 三随机种子最终复验。
- 密集、遮挡、复杂背景和失败案例可视化。

## 阶段 6：TensorRT C++

- PyTorch -> ONNX -> TensorRT 数值一致性验证。
- FP32、FP16、INT8 PTQ 精度和性能对比。
- 分开记录 GPU compute、传输+推理、完整端到端延迟。
- batch=1，固定 shape，充分预热，至少数百次正式迭代，报告 mean/P50/P95。

## 暂不纳入主线

- Jetson（只能作为可选扩展）
- 自采无人机数据
- 剪枝、QAT、蒸馏同时叠加
- 多种通用注意力模块堆叠
- 需要自定义 TensorRT Plugin 的复杂算子
- 将 Qt 界面包装成算法创新
