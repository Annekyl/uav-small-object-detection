# VisDrone2019-DET 数据集准备

## 使用 uv 建立环境

```powershell
uv python install 3.11
uv sync --extra dev
```

GPU 训练电脑后续执行 `uv sync --extra dev --extra train`，并按其 CUDA 环境安装经核验的 PyTorch 构建版本。

## 数据目录

数据集不进入 Git。将原始数据放在 `datasets/VisDrone2019-DET`，每个划分保留 `images` 和 `annotations`，转换结果写入同级 `labels`。

## 统计原始标注

```powershell
uv run visdrone-convert stats `
  --annotations datasets/VisDrone2019-DET/VisDrone2019-DET-train/annotations `
  --report results/data/train-statistics.json
```

## 转换训练集

```powershell
uv run visdrone-convert convert `
  --images datasets/VisDrone2019-DET/VisDrone2019-DET-train/images `
  --annotations datasets/VisDrone2019-DET/VisDrone2019-DET-train/annotations `
  --labels datasets/VisDrone2019-DET/VisDrone2019-DET-train/labels `
  --report results/data/train-conversion.json
```

类别 1-10 映射到 YOLO 的 0-9；类别 0（ignored regions）和类别 11（others）不作为训练目标。越界框会被裁剪，无效框会被过滤并计入报告。

## 验收条件

- `missing_annotations` 为 0。
- 对所有 `invalid_rows`、`invalid_boxes` 做检查。
- 随机可视化至少 50 张转换结果。
- 训练集和验证集分别保留统计与转换报告。
